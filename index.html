InstallScout

From silent switch finder to Intune upload. InstallScout reads a Windows installer without running it, finds the silent switches, builds a PSADT .intunewin package, and uploads the Win32 app to Microsoft Intune with detection, a logo, and optional supersedence.

Download 1.8.54 (.zip) Portable exe MSI

Version 1.8.54 for Windows 10 and 11. The zip contains the portable exe and the MSI. The portable exe runs without installation. The MSI installs to Program Files. The program does not run the installer. The interface is in English, and Dansk is in the top-right corner.

Not code-signed. Windows or company security may warn or block it. Choose Keep / Run anyway, ask IT to allow the file, or try it in a VM or Windows Sandbox without those policies.

What you get

  • A silent switch finder for the installer engine, including Inno, NSIS, MSI, InstallShield, WiX Burn, and others.
  • A check against WinGet and Chocolatey. The installer file is not uploaded.
  • One path to Intune: local .intunewin package, then upload with install, uninstall, detection, and logo.

Prerequisites

Windows 10 or Windows 11. Finding silent switches and building a local package does not need an Azure sign-in.

Upload to Intune also needs:

  • Microsoft Edge. Sign-in opens in an Edge profile.
  • An account that can create Win32 apps. In Microsoft Entra, that is the Intune Administrator role. In Intune role-based access control, Application Manager is enough. A custom role with the same app permissions works too.
  • One-time admin consent in the tenant for the Graph permission DeviceManagementApps.ReadWrite.All. Sign-in uses the public Microsoft Graph PowerShell client unless you set another Client ID. InstallScout does not create an app registration.
  • Conditional Access can still block that sign-in.
