Silent switch finder for Intune

InstallScout reads a Windows installer without running it. It finds the silent install switches for EXE, MSI, COM, and MSIX files and builds the silent command.

From that command it can build a PSAppDeployToolkit .intunewin package and upload the Win32 app to Microsoft Intune, with detection, a logo, and optional supersedence.

Download portable exe Download MSI

Version 1.8.45 for Windows 10 and 11. The portable exe runs without installation. The MSI installs to Program Files. The program does not run the installer. The interface is in English, and Dansk is in the top-right corner.

What you get

  • A silent switch finder for the installer engine, including Inno, NSIS, MSI, InstallShield, WiX Burn, and others.
  • A check against WinGet and Chocolatey. The installer file is not uploaded.
  • A local Intune package, then an upload with install, uninstall, and detection.
