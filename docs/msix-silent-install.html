MSIX and AppX — silent install switches

An MSIX is not an installer EXE, so there are no silent switches. You install it with PowerShell.

Version 1.8.74. Find the switches for any installer · All installer types.

Silent install command

Add-AppxPackage -Path "{file}"

Alternative:

Add-AppxProvisionedPackage -Online -PackagePath "{file}" -SkipLicense

Silent uninstall

Get-AppxPackage -Name "{PackageName}" | Remove-AppxPackage

{file} is the quoted path of the installer. {app} is the folder the app was installed to. {ProductCode} is the MSI product code.

Switches

SwitchMeaning
Add-AppxPackageInstall the package for the account that runs the command.
Add-AppxProvisionedPackageProvision the package so it installs for each user at sign-in. It needs an elevated session.
-SkipLicenseProvision without a license file.
-DependencyPathInstall framework packages first.

Rules that trip people up

  • Add-AppxPackage installs for the account that runs it. As System in Intune, that is not the signed-in user. Provision the package when every user needs it.
  • Frameworks that the package depends on, such as Microsoft.WindowsAppRuntime, must already be on the device or be installed first with -DependencyPath. InstallScout lists them from the package.
  • The package must be signed by a certificate the device trusts. An unsigned or self-signed package fails with a trust error.
  • Detection uses the package name, not a product code. Get-AppxPackage -Name returns the installed package and its version.

How to tell the installer is MSIX

The file ends in .msix, .appx, .msixbundle, or .appxbundle. These are zip archives with an AppxManifest.xml. They are not run as an EXE.

Use it in Intune

InstallScout detects an MSIX by package name and, when known, version. Try in Sandbox runs the Add-AppxPackage line in Windows Sandbox, so you see the error text before you upload.

Let InstallScout find it

Drop the file on InstallScout and click Analyze. It reads the file, names the engine, and writes this command with the path filled in. The installer is not run. The same lookup from a prompt:

.\InstallScoutPortable.exe --cli "C:\installers\setup.exe"

Then Intune package builds a PSADT .intunewin, and Upload to Intune sends the Win32 app.

Frequently asked questions

How do I install an MSIX silently?

Run Add-AppxPackage -Path "C:\path\app.msix" in PowerShell. There is no UI in PowerShell, so the install is silent.

How do I install an MSIX for all users?

Run Add-AppxProvisionedPackage -Online -PackagePath "C:\path\app.msix" -SkipLicense from an elevated session. The app installs for each user at their next sign-in.

Why does an MSIX fail with a dependency error?

A framework package such as Microsoft.WindowsAppRuntime is missing. Install it first, or pass it with -DependencyPath.
