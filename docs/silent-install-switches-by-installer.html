Silent install switches by installer type

There is no switch that silences every EXE. The right argument depends on the engine that built the installer. Find the engine first, then use its switch. {file} below is the quoted path of the installer.

How to find out which engine a file uses

Open the file properties and read Details. Look at the file in a hex viewer for strings such as Inno Setup, Nullsoft, or InstallShield. An .msi is always Windows Installer. InstallScout does this for you: it matches markers in the file, section names in the PE header, and files next to the installer, and then shows the engine with a confidence.

Frequently asked questions

Is there one silent switch that works for every EXE?

No. /S, /silent, /quiet, /VERYSILENT, and /qn belong to different engines. The wrong one is ignored or ends with an error. Find the engine first.

How do I find out which installer type an EXE is?

Search the file for strings such as Inno Setup, Nullsoft, InstallShield, or WiX. InstallScout does this automatically, names the engine, and writes the silent command without running the installer.

What if setup.exe /? shows nothing?

Many setup programs print no help text. The engine still has a known silent form. Identify the engine and use its switch.
