WiX Burn bundle — silent install switches

A WiX Burn bundle is an EXE that chains several packages. It takes the same few arguments every time.

Version 1.8.74. Find the switches for any installer · All installer types.

Silent install command

"{file}" /quiet

Alternative:

"{file}" /passive

Silent uninstall

"{file}" /uninstall /quiet

{file} is the quoted path of the installer. {app} is the folder the app was installed to. {ProductCode} is the MSI product code.

Switches

SwitchMeaning
/quietNo user interface.
/passiveProgress is shown, and there are no prompts.
/norestartDo not restart.
/log "%TEMP%\install.log"Write a log file.
/uninstallRemove the bundle.
/installInstall. This is the default, so it is not needed.

Rules that trip people up

  • /quiet is the silent switch. /passive shows progress and no prompts.
  • /install is already the default, so it is left out of the line.
  • Add /norestart when the bundle must not restart the machine. Exit code 3010 reports a pending restart.
  • Uninstall by running the same bundle with /uninstall /quiet. The bundle has to be available at that path, or cached by Windows.

How to tell the installer is WiX Burn

A Burn bundle is an EXE built with the WiX toolset that chains packages such as VC++ runtimes and the main MSI.

Use it in Intune

Package the bundle as the install file and use /uninstall /quiet for the uninstall line. Detection reads the bundle's entry under the uninstall key and compares the version.

Let InstallScout find it

Drop the file on InstallScout and click Analyze. It reads the file, names the engine, and writes this command with the path filled in. The installer is not run. The same lookup from a prompt:

.\InstallScoutPortable.exe --cli "C:\installers\setup.exe"

Then Intune package builds a PSADT .intunewin, and Upload to Intune sends the Win32 app.

Frequently asked questions

What is the silent switch for a WiX Burn bundle?

Use "setup.exe" /quiet. Add /norestart to prevent a restart.

What is the difference between /quiet and /passive?

/quiet shows nothing. /passive shows the progress and no prompts.

How do I uninstall a WiX Burn bundle silently?

Run the bundle with /uninstall /quiet.
