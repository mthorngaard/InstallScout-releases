InstallShield — silent install switches

InstallShield comes in two forms. A setup that wraps an MSI takes /s /v"/qn". A pure InstallScript setup needs a recorded response file.

Version 1.8.74. Find the switches for any installer · All installer types.

Silent install command

"{file}" /s /v"/qn"

Alternative:

"{file}" /s /sms

{file} is the quoted path of the installer. {app} is the folder the app was installed to. {ProductCode} is the MSI product code.

Switches

SwitchMeaning
/sSilent setup.
/v"/qn"Pass /qn to the MSI inside. The quotes are part of the switch.
/v"/qn REBOOT=ReallySuppress"Pass several MSI arguments in one quoted string.
/f2"%TEMP%\install.log"Write the setup log to a file.
/smsKeep the setup process running until the install is done.
/rRecord a response file (setup.iss) for an InstallScript setup.
/s /f1"C:\setup.iss"Play back a recorded response file silently.

Rules that trip people up

  • /qn is passed to the MSI through /v"...". Without the quotes, the arguments are read by the wrapper and not by the MSI.
  • An older InstallScript setup may need a recorded setup.iss: run setup.exe /r once, then setup.exe /s /f1"C:\setup.iss".
  • Put every MSI argument inside one /v"..." string. Quote values that have spaces with an extra pair of quotes.
  • When the setup extracts an MSI, you can often install that MSI with msiexec directly. That is the more reliable line when it works.

How to tell the installer is InstallShield

The file contains the text InstallShield. A setup with an MSI inside accepts /v. A pure InstallScript setup has no MSI.

Use it in Intune

InstallShield has the lowest first-try rate of the common engines. InstallScout puts it at about 60% for the silent install. Treat a result below about 40% confidence as a draft and test it in Windows Sandbox or a VM before you upload.

Let InstallScout find it

Drop the file on InstallScout and click Analyze. It reads the file, names the engine, and writes this command with the path filled in. The installer is not run. The same lookup from a prompt:

.\InstallScoutPortable.exe --cli "C:\installers\setup.exe"

Then Intune package builds a PSADT .intunewin, and Upload to Intune sends the Win32 app.

Frequently asked questions

What is the silent switch for InstallShield?

Use "setup.exe" /s /v"/qn". /s makes the wrapper silent, and /v"/qn" hands /qn to the MSI inside.

How do I make a setup.iss for InstallShield?

Run setup.exe /r and click through the wizard. That records setup.iss. Then install silently with setup.exe /s /f1"C:\setup.iss".

Why are the quotes after /v needed?

The wrapper reads its own switches. Everything inside /v"..." is passed on to msiexec unchanged.
