Advanced Installer — silent install switches

An Advanced Installer EXE is a bootstrapper around an MSI. The bootstrapper and the MSI each take a switch.

Version 1.8.74. Find the switches for any installer · All installer types.

Silent install command

"{file}" /exenoui /qn

Alternative:

"{file}" /exenoui /passive /qn

Silent uninstall

"{file}" /exenoui /x // /qn

{file} is the quoted path of the installer. {app} is the folder the app was installed to. {ProductCode} is the MSI product code.

Switches

SwitchMeaning
/exenouiNo interface for the EXE bootstrapper.
/qnPassed on to the MSI: no interface.
/passiveShow progress, no prompts.
/exenoupdatesDo not check for updates.

Rules that trip people up

  • /S and /VERYSILENT typically produce Invalid command line. They belong to other engines.
  • /exenoui silences the bootstrapper and /qn silences the MSI. You need both.
  • /exenoupdates stops the setup from looking for a newer version at install time.
  • The uninstall line is the bootstrapper again. InstallScout writes it as "{file}" /exenoui /x // /qn.

How to tell the installer is Advanced Installer

The setup is an EXE bootstrapper around an MSI, and the file mentions Advanced Installer. Running it with /S or /VERYSILENT often prints Invalid command line.

Use it in Intune

Treat the bootstrapper as the install file. The MSI inside has a product code, which is a stable key for detection when you can read it.

Let InstallScout find it

Drop the file on InstallScout and click Analyze. It reads the file, names the engine, and writes this command with the path filled in. The installer is not run. The same lookup from a prompt:

.\InstallScoutPortable.exe --cli "C:\installers\setup.exe"

Then Intune package builds a PSADT .intunewin, and Upload to Intune sends the Win32 app.

Frequently asked questions

What is the silent switch for Advanced Installer?

Use "setup.exe" /exenoui /qn.

Why does /S give Invalid command line on Advanced Installer?

/S is not an Advanced Installer switch. The bootstrapper expects /exenoui and the MSI switch /qn.
