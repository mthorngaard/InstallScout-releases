Inno Setup — silent install switches

Inno Setup has its own switches. They are not the MSI switches and not NSIS /S.

Version 1.8.74. Find the switches for any installer · All installer types.

Silent install command

"{file}" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-

Alternative:

"{file}" /SILENT /NORESTART

Silent uninstall

"{app}\unins000.exe" /VERYSILENT /NORESTART

{file} is the quoted path of the installer. {app} is the folder the app was installed to. {ProductCode} is the MSI product code.

Switches

SwitchMeaning
/VERYSILENTNo wizard, no progress window.
/SILENTNo wizard, but a progress window is shown.
/SUPPRESSMSGBOXESAnswer message boxes with the default choice.
/NORESTARTDo not restart, even if setup asks.
/SP-Skip the prompt "This will install ... Do you wish to continue?".
/LOG="%TEMP%\install.log"Write a log file.
/DIR="C:\Program Files\App"Set the install folder.
/MERGETASKS=!desktopiconChange tasks. An exclamation mark switches a task off.
/NORESTARTAPPLICATIONSDo not restart applications that were closed.

Rules that trip people up

  • /S is not the silent switch for Inno Setup. Use /VERYSILENT.
  • /NORESTART is Inno's own switch, so it stays in the line.
  • /SP- removes the first confirmation. Without it a silent install can still stop at that prompt.
  • Switches with a value need quotes around the value when it has a space: /DIR="C:\Program Files\App".
  • The uninstaller is in the install folder, normally as unins000.exe. A second uninstaller is unins001.exe.

How to tell the installer is Inno Setup

The setup contains the text Inno Setup, and the uninstaller is called unins000.exe.

Use it in Intune

An Inno app is usually a per-machine install and runs as System. When it installs for the current user only, it has to run as User, and a detection script that runs as System reads another account's registry. InstallScout picks System or User from the engine and the command, and detection matches the product name, publisher, and version.

Let InstallScout find it

Drop the file on InstallScout and click Analyze. It reads the file, names the engine, and writes this command with the path filled in. The installer is not run. The same lookup from a prompt:

.\InstallScoutPortable.exe --cli "C:\installers\setup.exe"

Then Intune package builds a PSADT .intunewin, and Upload to Intune sends the Win32 app.

Frequently asked questions

What is the silent switch for Inno Setup?

Use "setup.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-. /VERYSILENT hides the wizard and the progress window.

Why does /S not work on an Inno Setup installer?

/S belongs to NSIS. Inno Setup ignores it, so the wizard opens. Use /VERYSILENT or /SILENT.

What is the difference between /SILENT and /VERYSILENT?

/SILENT shows a progress window. /VERYSILENT shows nothing. Use /VERYSILENT for Intune and other unattended installs.

How do I uninstall an Inno Setup app silently?

Run "C:\Program Files\App\unins000.exe" /VERYSILENT /NORESTART.
