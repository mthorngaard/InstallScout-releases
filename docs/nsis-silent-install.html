NSIS (Nullsoft Scriptable Install System) — silent install switches

NSIS installers take one common silent switch, /S. Two rules decide whether it works.

Version 1.8.74. Find the switches for any installer · All installer types.

Silent install command

"{file}" /S

Silent uninstall

"{app}\uninstall.exe" /S

{file} is the quoted path of the installer. {app} is the folder the app was installed to. {ProductCode} is the MSI product code.

Switches

SwitchMeaning
/SSilent install. It must be a capital S.
/D=C:\Program Files\AppSet the install folder. It must be the last argument and has no quotes, even with spaces.
/NCRCSkip the integrity check of the installer.
_?=C:\Program Files\AppOn the uninstaller: run in place, so the command waits until it is done.

Rules that trip people up

  • /S must be a capital S. NSIS treats /s as another argument.
  • /D= sets the install folder. It must be the last argument and must not be quoted, even when the path has spaces.
  • Custom NSIS scripts can add switches of their own, and some ignore /S. Check the vendor's notes when the wizard still opens.
  • The NSIS uninstaller copies itself to a temporary folder and starts there, so the command returns at once. Add _?=<install folder> as the last argument to run it in place and wait for it.

How to tell the installer is NSIS

The file contains the text Nullsoft Install System. The uninstaller is usually uninstall.exe or Uninstall.exe in the install folder.

Use it in Intune

Many NSIS apps install per user. Check the install folder and the registry hive before you choose System or User, because detection has to read the same account. InstallScout picks the context from the engine and the command, and detection matches the product name, publisher, and version.

Let InstallScout find it

Drop the file on InstallScout and click Analyze. It reads the file, names the engine, and writes this command with the path filled in. The installer is not run. The same lookup from a prompt:

.\InstallScoutPortable.exe --cli "C:\installers\setup.exe"

Then Intune package builds a PSADT .intunewin, and Upload to Intune sends the Win32 app.

Frequently asked questions

What is the silent switch for NSIS?

Use "setup.exe" /S. The S is a capital letter.

How do I set the install folder for an NSIS installer?

Add /D=C:\Program Files\App as the last argument, without quotes.

Why does the NSIS uninstaller return immediately?

It copies itself to a temporary folder and exits. Run it as uninstall.exe /S _?=C:\Program Files\App to make the command wait for the uninstall.
